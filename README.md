# Ges.Ca.

Gestionale per aziende e negozi su **AS/400 e IBM i** (da OS/400 V4R3 in poi): anagrafiche, magazzino, vendite e
acquisti, banco e cassa, contabilità, produzione, stampe. Moduli di settore attivabili: ristorante, matricole, lotti,
taglie e colori, ritenute, MRP e altri.

Si usa da qualunque terminale 5250.

## Scaricare

Il pacchetto è nelle [Release](../../releases/latest): `gesca-VERSIONE.zip` contiene il file di salvataggio della
libreria, la guida d'installazione (`INSTALLA.txt`), il manuale (`MANUALE.pdf`), la licenza e le impronte `SHA256SUMS`.
